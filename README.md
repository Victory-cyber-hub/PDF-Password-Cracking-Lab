# PDF Password Recovery Labs

**Author:** Victory Ihuoma Amadi

## About this project

This repository contains screenshots from two PDF password recovery practical modules. The work was completed on sample PDF files provided for the lab.

## Module 1: Password Cracking with John the Ripper (JTR)

This module used a PDF hash extractor and John the Ripper's graphical tool, Johnny.

The screenshots show the hash being extracted from the protected PDF, the hash being used in Johnny, an attack being started, and the PDF being opened after its password was recovered.

Screenshots are in `module-1-john-the-ripper/screenshots/`.

## Module 2: Password Cracking with Networkwalks Tools

This module used the Networkwalks Hash Calculator and Password Cracker.

The screenshots show the PDF hash being obtained, entered into the Password Cracker, and the password being recovered. The final screenshot shows the PDF opened successfully.

Screenshots are in `module-2-networkwalks-tools/screenshots/`.

## Results

- Module 1: The password for the lab PDF was recovered, and the PDF was opened.
- Module 2: The password for the lab PDF was recovered using the Networkwalks tools, and the PDF was opened.

## Tools used

- John the Ripper / Johnny
- Online PDF hash extractor
- Networkwalks Hash Calculator
- Networkwalks Password Cracker

## Note

These exercises were carried out on the PDF files supplied for the practical work. This repository is for documenting the lab process and its results. Only use password recovery tools on files you own or have permission to test.
